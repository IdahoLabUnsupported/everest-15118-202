# ESDP ASN.1 source provenance

`esdp_definitions.asn` is derived from ISO/PAS 15118-202:2025 (ed-1), but it is
not an exact copy of the ISO-hosted schema. It is **generated, not committed**:
run `generate_esdp_definitions.sh` in this directory to download and derive it.

- Upstream ISO schema: https://standards.iso.org/iso/pas/15118/-202/ed-1/en/ESDPExtensions.asn
- Normalized core source (generated by core's `fetch_asn1.sh`): `chgex-everest-core/lib/3rd_party/asn1/esdp_extensions.asn`
- Local Python EVCC schema: `iso15118/evcc/asn1/esdp_definitions.asn`

## Why It Differs

`chgex-everest-core` obtains the ASN.1 source through
`lib/3rd_party/asn1/fetch_asn1.sh`, which preserves the ISO source as
`*.asn.orig` and normalizes an upstream transcription issue where information
object field references are split across lines. Core then uses
`lib/3rd_party/asn1/regenerate_asn1c.sh` to derive an asn1c-compatible codegen
schema.

The chgex-ext-switchev-iso15118 repository uses Python `asn1tools` at runtime. For that runtime,
`esdp_definitions.asn` intentionally keeps the outer `ESDPExtension` envelope as:

```asn1
ESDPExtension ::= SEQUENCE {
  extensionID     OCTET STRING (SIZE (16)),
  extensionValue  OCTET STRING,
  ...
}
```

The Python adapter in `esdp_asn1_main.py` encodes and decodes each typed
extension payload explicitly, then places those bytes in `extensionValue`.

## Intentional Deviations

- The upstream `EXTENSION ::= CLASS` information object class is omitted.
- The upstream `ExtensionSet` information object set is omitted.
- `ESDPExtension.extensionID` is represented as `OCTET STRING (SIZE (16))`
  instead of `EXTENSION.&id ({ExtensionSet})`.
- `ESDPExtension.extensionValue` is represented as `OCTET STRING` instead of
  `EXTENSION.&Type({ExtensionSet}{@.extensionID})`.
- The module name is local to this Python-compatible schema.

All other ESDP extension type and field names should stay aligned with
`chgex-everest-core/lib/3rd_party/asn1/esdp_extensions.asn`.

## Maintenance Rule

If the envelope adaptation needs to change, edit the awk transform in
`generate_esdp_definitions.sh` and regenerate. Do not hand-edit the generated
file or treat it as a verbatim ISO download.
