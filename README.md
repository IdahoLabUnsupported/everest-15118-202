# everest-15118-202
EVerest-15118-202 implements the ISO 15118-202 Extensible SECC Discovery Protocol and Event Notification Protocol in EVerest, an open-source EV charging software stack, to improve diagnostic communication between electric vehicles and charging equipment. It builds on prior ChargeX Consortium work by Idaho National Laboratory and NREL.

This repo contains the necessary changes to the everst-core and ext-switchev-iso15118 to implement ISO15118-202 Extensible SECC Discovery Protocol. Event Notification Protocol implementation is yet to be completed and tested.
